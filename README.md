# Dollhouse interactive tools (draft)

Seven self-contained pages, one folder each with an index.html: estimator, digital-lab, brief-builder, before-after-slider, style-explorer, deliverables-explorer, proof-strip.

Status: drafts, nothing is live on the site. The repo is private. GitHub Pages is NOT switched on, because Pages needs a public repo and that is the owner's call. To use: make the repo public, enable Pages on main, then in Wix use Embed a site with each page address, e.g. https://brooktheebaddie.github.io/dollhouse-interactive-tools/estimator/index.html

Suggested embed heights: estimator 1400px desktop / 1900px mobile; digital-lab 900 / 1500; brief-builder 1000 / 1400; before-after-slider 900; style-explorer 950 / 1300; deliverables-explorer 900 / 1500; proof-strip 480.

Images load from their hosted addresses, so no image files are needed here. Start a project links point at the current services page and need the final form address. proof-strip is a labelled design draft: live Instagram and LinkedIn feeds need server-side credentials, then set FEED_URL.

Tested in headless Chrome at 390px and 1280px: brief-builder, before-after-slider, style-explorer, deliverables-explorer (proof-strip on a trimmed copy). Estimator and digital-lab are the earlier originals, not re-run in a browser.
